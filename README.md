# Татар әкиятләре — татарский каждый день

Две рубрики приходят в ваш Telegram-канал сами (время по Казани):

| Время | Рубрика | Для кого |
| --- | --- | --- |
| 08:00 | Фраза дня (голосовое) + викторина-опрос | взрослые |
| 19:00 | Сказка на ночь: аудио + текст на кириллице и латинице | дети и родители |

Озвучка — женский голос TatarTTS. Сервер не нужен, всё работает бесплатно на GitHub.

---

## Шаг 1. Создайте канал в Telegram (5 минут)

1. Telegram → карандаш → **Новый канал**.
2. Название, например: «Татар әкиятләре — сказки на ночь».
3. Тип — **Публичный**, придумайте ссылку, например `tatar_ekiyatlar`.
   Запомните её: это будет `@tatar_ekiyatlar`.

## Шаг 2. Создайте бота (5 минут)

1. Найдите в Telegram **@BotFather**, нажмите «Старт».
2. Отправьте `/newbot`, введите имя и логин бота (логин должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** — длинную строку вида `1234567890:AAH...`.
   Это пароль бота, никому его не показывайте.
4. Откройте свой канал → **Администраторы** → **Добавить администратора** →
   найдите своего бота → разрешите **публикацию сообщений**.

## Шаг 3. Загрузите проект на GitHub (10 минут)

1. Зарегистрируйтесь на [github.com](https://github.com), если ещё нет аккаунта.
2. Справа вверху **+** → **New repository**. Название: `tatar-skazki`,
   тип **Public** → **Create repository**.
3. На странице репозитория нажмите ссылку **uploading an existing file**.
4. Распакуйте архив на компьютере и **перетащите всё содержимое папки**
   `tatar-skazki` в окно браузера → **Commit changes**.

> Папка `.github` на компьютере может быть скрытой. Если она не загрузилась:
> в репозитории **Add file → Create new file**, в поле имени напишите
> `.github/workflows/daily-story.yml` и вставьте туда текст этого файла из архива.

## Шаг 4. Впишите токен и канал в «секреты» (3 минуты)

Репозиторий → **Settings** → слева **Secrets and variables → Actions** →
**New repository secret**. Создайте два секрета:

| Name | Secret |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | `@ваш_канал` (с собачкой) |

## Шаг 5. Проверка

1. Вкладка **Actions** → слева «Сказка дня» → **Run workflow** → зелёная кнопка.
2. Первый запуск дольше (скачивается голос), примерно через 5 минут в канале появится сказка.
3. Если стоит красный крестик — нажмите на запуск, там написана ошибка.
   Скопируйте её мне, разберёмся.

Так же проверьте утреннюю рубрику: **Actions → «Фраза дня» → Run workflow**.

Дальше всё идёт само: фраза в 08:00, сказка в 19:00.

## Как добавлять сказки

- Папка `stories` → **Add file → Create new file**.
- Имя файла по порядку: `004-nazvanie.md`, `005-...md` (номер в начале важен).
- Первая строка — заголовок с решёткой: `# Название сказки`.
- Ниже — текст сказки на кириллице. Латиница и аудио сделаются сами.

Дата старта и повтор сказок — в файле `config.txt`.

## Как добавлять фразы для взрослых

Файл `phrases/phrases.csv` — это таблица, GitHub показывает её как таблицу.
Чтобы добавить фразу: откройте файл → карандаш ✏️ → новая строка в конце:

```
"Фраза на татарском","Перевод","Слово для викторины","верный ответ","неверный 1","неверный 2"
```

Одна строка = один день. Порядок вариантов в опросе перемешивается сам.

## Важно знать

- **Проверка текстов.** Сказки-образцы и 30 фраз написаны с помощью ИИ.
  Перед публикацией их обязательно должен прочитать носитель языка.
- **Латиница** делается автоматически по упрощённым правилам и может ошибаться
  в отдельных словах (особенно к/q и г/ğ).
- **Голос** — женский голос TatarTTS (Институт прикладной семиотики АН РТ и ISSAI,
  лицензия MIT). Модель (~110 МБ) при первом запуске скачивается с Google Диска
  разработчиков и дальше хранится в кэше GitHub. Сохраните себе копию файлов
  на случай, если ссылку удалят. Лучшие сказки со временем можно перезаписать живым голосом: просто положите свой mp3
  в папку `audio` с тем же именем, что и сказка (`001-kuyan.mp3`),
  и бот будет отправлять его вместо ИИ-озвучки.
- Время публикации меняется в файле `.github/workflows/daily-story.yml`,
  строка `cron` (время указывается по UTC, Казань = UTC+3).

## Как устроено

| Файл | Что делает |
| --- | --- |
| `stories/*.md` | тексты сказок |
| `audio/*.mp3` | готовые озвучки |
| `scripts/post_story.py` | выбирает сказку дня и отправляет в канал |
| `scripts/tts.py` | озвучка татарского голосом TatarTTS |
| `scripts/get_model.py` | скачивает голос TatarTTS |
| `phrases/phrases.csv` | фразы дня и вопросы викторины |
| `scripts/post_phrase.py` | публикует фразу дня и викторину |
| `.github/workflows/morning-phrase.yml` | расписание утренней рубрики |
| `scripts/translit.py` | кириллица → латиница |
| `.github/workflows/daily-story.yml` | расписание запуска |
